<ktjs-features section-title="这套封装给你什么" tinted>

<ktjs-feature icon="lucide:bar-chart-3" title="完整公开面">`init`、`use`、`registerTheme` / `registerMap` / `registerLocale`，`format` / `time` / `graphic` 命名空间，以及每个图表、组件、渲染器的 installer。</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="选项不是 dynamic">系列与组件选项是由上游声明生成的 `external interface`，拼错字段就是编译错误。</ktjs-feature>

<ktjs-feature icon="lucide:type" title="具名取值是类型">`AxisTypes.category`、`SeriesTypes.line`、`TooltipTriggers.axis` —— 每个都是自己密封接口里的常量，而不是裸字符串。</ktjs-feature>

<ktjs-feature icon="lucide:package" title="模块化仍然模块化">`EChartsCore` 加你引用的 installer；只有某处写了 `ECharts`，完整包才会进来。</ktjs-feature>

<ktjs-feature icon="lucide:box" title="含 3D 与 WebGL">`ktjs-echarts-gl` 封装 `echarts-gl` 2.1：`bar3D`、`scatterGL`、`globe`、后处理选项与 GL installer。</ktjs-feature>

<ktjs-feature icon="lucide:server" title="选项可以从任何地方来">`kmp-echarts-json` 把同一套选项 schema 建模成 `@Serializable` 类，JVM 或 native 后端可以先拼好 JSON 再交给图表。</ktjs-feature>

</ktjs-features>
