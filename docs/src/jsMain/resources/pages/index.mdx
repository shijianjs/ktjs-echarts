<ktjs-features section-title="What the wrapper gives you" tinted>

<ktjs-feature icon="lucide:bar-chart-3" title="The whole public surface">`init`, `use`, `registerTheme` / `registerMap` / `registerLocale`, the `format` / `time` / `graphic` namespaces and every chart, component and renderer installer.</ktjs-feature>

<ktjs-feature icon="lucide:shield-check" title="Options, not `dynamic`">Series and component options are `external interface` types built from the upstream declarations, so a misspelt field is a compile error.</ktjs-feature>

<ktjs-feature icon="lucide:type" title="Named values are typed">`AxisTypes.category`, `SeriesTypes.line`, `TooltipTriggers.axis` — each is a constant of its own sealed interface instead of a bare string.</ktjs-feature>

<ktjs-feature icon="lucide:package" title="Modular builds stay modular">`EChartsCore` plus the installers you reference; the full bundle is only pulled in when something names `ECharts`.</ktjs-feature>

<ktjs-feature icon="lucide:box" title="3D and WebGL included">`ktjs-echarts-gl` wraps `echarts-gl` 2.1: `bar3D`, `scatterGL`, `globe`, the post-effect options and the GL installers.</ktjs-feature>

<ktjs-feature icon="lucide:server" title="Options from anywhere">`kmp-echarts-json` models the same option schema as `@Serializable` classes, so a JVM or native backend can hand a JSON payload to the chart.</ktjs-feature>

</ktjs-features>
